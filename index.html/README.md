# ระบบสอบออนไลน์ (Online Exam System)

เว็บสอบออนไลน์ที่ติดตั้งง่าย ใช้ Node.js + Express (ไม่ต้องมีฐานข้อมูลภายนอก เก็บข้อมูลเป็นไฟล์ JSON ใน `data/`)

## เริ่มใช้งาน
1. ติดตั้ง Node.js 18 ขึ้นไป
2. เปิดเทอร์มินัลในโฟลเดอร์นี้ แล้วรัน
   ```
   npm install
   npm start
   ```
3. เปิด http://localhost:3000
4. ผู้ดูแลเริ่มต้น: `admin` / `admin1234`  → **ควรเปลี่ยนก่อนใช้งานจริง** โดยตั้งค่า (ก่อนรันครั้งแรก)
   `ADMIN_USER=ชื่อ ADMIN_PASS=รหัสผ่านใหม่ npm start`
   - `ALLOW_REGISTER=0` = ปิดการสมัครเอง (ให้ผู้ดูแลเพิ่มผู้สอบแทน)
   - `PORT=8080` = เปลี่ยนพอร์ต

## ฟีเจอร์
**ผู้ดูแล:** สร้าง/แก้ไข/ลบข้อสอบ · กำหนดเวลาทำ เวลาเปิด-ปิด · นำเข้าโจทย์จาก CSV · เพิ่มผู้สอบเป็นกลุ่ม ·
ติดตามผู้สอบสดทุก 5 วินาที (สถานะ จำนวนที่ตอบ จำนวนครั้งที่ละเมิด ขาดการเชื่อมต่อ) · ดูคำตอบ/ไฟล์/บันทึกเหตุการณ์ทั้งหมด ·
ให้คะแนนข้ออัตนัยและข้อส่งไฟล์ · ส่งออกผลเป็น CSV

**ผู้สอบ:** ทำข้อสอบแบบเต็มจอ · นาฬิกานับถอยหลังตามเซิร์ฟเวอร์ · บันทึกคำตอบอัตโนมัติทุก 5 วินาที · อัปโหลดไฟล์ (≤10MB) ·
ส่งแล้วแก้ไขไม่ได้ (เซิร์ฟเวอร์บังคับ) · หมดเวลาหรือละเมิดเกินกำหนด = ส่งอัตโนมัติและตรวจให้ทันที

**ประเภทข้อสอบ:** ปรนัย / คำตอบสั้น (ตรวจอัตโนมัติ) · อัตนัย / ส่งไฟล์ (ผู้ดูแลตรวจ)

## รูปแบบไฟล์ CSV นำเข้าโจทย์
```
type,โจทย์,ตัวเลือก,เฉลย,คะแนน
mcq,"เมืองหลวงของไทยคือ?",กรุงเทพ|เชียงใหม่|ภูเก็ต,1,2
short,"2+2 เท่ากับเท่าไร",,4|สี่,1
essay,"อธิบายวัฏจักรของน้ำ",,,5
file,"ส่งไฟล์งานของคุณ",,,10
```
(`mcq` เฉลย = เลขลำดับตัวเลือกที่ถูก เริ่มที่ 1)

## ข้อจำกัดที่ควรรู้
เว็บเบราว์เซอร์ **ล็อกเครื่องผู้สอบได้ไม่สมบูรณ์** ระบบนี้ใช้การบังคับเต็มจอ ตรวจจับการสลับแท็บ/หน้าต่าง บล็อกคัดลอก-วาง
คลิกขวา และปุ่มลัด แล้วบันทึกเป็นหลักฐาน แต่ยังเลี่ยงได้ เช่น ใช้อีกอุปกรณ์ สำหรับการสอบที่สำคัญมากควรใช้ร่วมกับ
Safe Exam Browser หรือมีผู้คุมสอบ

## นำขึ้นออนไลน์
ใช้ได้กับ VPS / Render / Railway ที่รัน Node.js ได้ — **ต้องใช้ HTTPS** (จำเป็นสำหรับโหมดเต็มจอและความปลอดภัยของรหัสผ่าน)
และควรตั้ง volume ถาวรให้โฟลเดอร์ `data/` เพื่อไม่ให้ข้อมูลหาย · สำรองไฟล์ `data/` สม่ำเสมอ
